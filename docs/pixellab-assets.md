# PixelLab assets

Generated with PixelLab Pro Flash for Pixel Constellations:

| File | Role | Size |
| --- | --- | --- |
| `menu_icon.png` | Launcher icon (constellation “8”) | 25×25 |
| `star.png` | Decorative sparkle | 16×16 |
| `star_node.png` | Occasional bright constellation node | 16×16 |
| `moon.png` | Crescent moon decoration | 24×24 |
| `nebula.png` | Corner nebula wash | 48×48 |

Near-black pixels on sprites (except the menu icon) are keyed to transparent via
`tools/prepare_images.py` so they composite cleanly with `GCompOpSet`.
